# PPT 示例验证

验证日期：2026-10-31。三个PPTX使用 Codex bundled Artifact Tool 制作；逐页PNG来自最终文件重新导入后的渲染，分辨率为1920×1080。共9页均已实际查看，检查中文字体、换行、边距、表格、图片裁切与页码。

| 文件 | 页数 | 各页原生形状数 | 各页文字片段数 | 原生表格 | 图片 |
|---|---:|---|---|---|---|
| craft.pptx | 3 | 8 / 33 / 36 | 8 / 11 / 14 | 无 | 封面1张独立图片 |
| business.pptx | 3 | 12 / 27 / 5 | 12 / 21 / 25 | 第3页1个 | 无 |
| culture.pptx | 3 | 16 / 18 / 11 | 6 / 7 / 24 | 第3页1个 | 无 |

验证结果：

- 三个文件的ZIP CRC、包结构、3页总数与16:9几何通过。
- 依设计选择声明 PingFang SC、Songti SC、Georgia 字体；相关字型检查通过。
- 商务和文化第3页原生表格检查通过；两表的单元格文字与其他页面文字保留可编辑对象。
- 三个最终文件均通过 Artifact Tool 再次导入，并从该最终文件渲染全部9页。
- 所有页面含“原创概念演示”；没有实际经营结果、客户身份、活动日期与场所等虚构实绩。
- 幻灯片XML未发现本机用户路径；工艺摄影为独立图片，其他纸张、物件与抽象作品为原生几何对象。
- 三张1600×1000组合预览是展示图片；它们不代替PPTX的原生编辑结构。

源文件哈希与逐页结构统计见 [verification.json](verification.json)。构建过程完整校验回执位于被忽略的 `.build/`，不作为公开示例内容上传。

当前验证覆盖生成工具、包结构、重新导入与实际渲染；未逐一测试所有 PowerPoint/Google Slides 版本。若其他系统缺少指定字体，需安装相应字体或在重建时用环境变量指定替代字体。
