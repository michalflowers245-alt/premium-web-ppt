# 网页实施与验收

用于官网、作品集、品牌页、产品介绍和需要高级视觉的既有页面。尊重已有技术栈和用户指定的建站方式，不为换风格重建业务逻辑。

## 从内容决定页面节奏

- 首屏先回答“是什么、为什么值得看、下一步做什么”；品牌/艺术体验可以先用作品建立气质，但主要入口应能找到。不要把所有项目都写成同一段超大口号。
- 用几种有作用的版式交替：主视觉、图文叙述、作品索引、产品近景、数据/证据、联系或购买。数量由内容决定。
- 把来源官网的“导航＋大图”拆成可迁移关系：导航高度、图像占比、标题对齐、CTA位置、下一屏提示。用户页面不需要假购物车、无效搜索或品牌专有功能。
- 工具台、数据表和表单可以借用字体、间距和配色，但优先完成任务的效率；不能为了画廊感藏起操作或把字段铺成巨幅海报。

## 设计变量：起点而非硬模板

在当前项目的变量系统表达颜色、字型、字号阶梯、间距、内容宽度、边框、圆角和动效。已有设计系统先调整它，不再叠一套。

| 项目 | 桌面起点 | 手机起点 |
|---|---|---|
| 外边距 | clamp(24px, 4vw, 80px) | 16–24px |
| 内容最大宽 | 阅读区680–800px；宽版1280–1600px | 随视口自适应 |
| 标题 | clamp(40px, 6vw, 104px)；中文按字数缩放 | 常用32–52px，保证自然换行 |
| 正文 | 16–20px，中文行高约1.6–1.8 | 16–18px |
| 段落/区域间距 | 以8px节奏组织，主区约72–144px | 主区约40–72px |
| 细线 | 1px低对比色，承担分组/边界作用 | 保持可见 |

不能从这些数值推定原站CSS。首屏高度按内容与视口决定；使用满屏时考虑svh/dvh和手机浏览器栏。

## 图像、字体、动效

- 指定aspect-ratio和裁切焦点；桌面宽景图到手机时单独调整，不让人脸、商品或图中关键文字被裁掉。不要把横图强塞成极高竖图。
- 优先使用实际存在并能加载的字体；有中文回退与加载失败回退。展示字体适合标题不代表适合长段正文。
- 导航、按钮、表单和图片具备合适语义、可见焦点及触控尺寸。正文对比度通常至少4.5:1，大字至少3:1；装饰文字不能承载关键信息。
- 动效用来提示进入、状态或层级。常规过渡可从160–280ms起步，空间揭示约400–700ms；这是新设计建议，不是对原站实测。支持reduced motion，不能用滚动劫持妨碍阅读。
- 首屏大图优先清晰与加载效率；下方图按需加载并保留尺寸，避免布局跳动。只有内容需要时才加视频/3D。

## 实际检查

在真实浏览器检查至少一个宽桌面视口和一个约390px手机视口；增加与页面相关的窄桌面/平板、长标题、菜单展开、表单错误或空内容状态。

查看截图，同时实际操作主要导航、CTA、菜单、切换、键盘焦点与表单。修正横向溢出、图文覆盖、移动端断层、字体回退、图片加载失败和无效链接。若浏览器不可用，区分已做代码检查与未做的视觉/交互验证。
