# 三组可编辑 PPT 概念演示

每组3页，16:9。原生标题、正文、几何图形、流程与表格可以在 PowerPoint 中修改。摄影是独立图片对象；预览图片不承担可编辑性。

| 案例 | 源文件 | 内容 |
|---|---|---|
| 工艺品牌「缓物」 | [craft.pptx](craft/craft.pptx) | 品牌封面、材料方向、系列概念 |
| AI门店试点方案 | [business.pptx](business/business.pptx) | 试点判断、接待路径、指标框架 |
| 文化策展「光的秩序」 | [culture.pptx](culture/culture.pptx) | 展览封面、原创作品、观看动线 |

三组均为原创概念演示，不是真实客户项目或经营结果。工艺图由 GPT ImageGen 生成；文化案例的抽象作品由原生几何对象绘制。示例没有引用任何客户私人资料。

## 重新制作

使用包含 `@oai/artifact-tool` 的 Codex 演示制作运行时。此依赖由运行环境提供，本仓库不附带该专用运行时或系统字体。

```bash
node examples/ppt/build.mjs
# 单独重建
node examples/ppt/build.mjs business
```

脚本从自身位置定位仓库，不依赖执行目录。默认字型为 PingFang SC、Songti SC 和 Georgia；可通过 `PPT_SANS_FONT`、`PPT_SERIF_FONT`、`PPT_LATIN_FONT` 指定已经安装、支持相应字符的其他字体。

如果运行时不通过普通包查找暴露 Artifact Tool，可将 `ARTIFACT_TOOL_PACKAGE` 指向该包目录。可选的 `PRESENTATIONS_SKILL_DIR` 指向演示技能目录，`PPT_PYTHON` 指定其配套Python解释器；提供时会运行该环境的包结构、几何、字型、原生表格与导入检查。构建中间文件写入 `.build/`，最终PPTX再次导入后渲染为逐页PNG。

## 可复用提示词

**工艺品牌：** 使用 `$premium-web-ppt`，为一个虚构的纸品与香氛品牌做3页可编辑PPT。以暖白、橄榄和材料图像组织品牌封面、材料方向、系列概念。参考045的材料叙事、049的同色组照和195的图册节奏；借构图与阅读关系，使用原创素材。全部文字、形状与图注可编辑，清楚标注概念演示。

**商务方案：** 使用 `$premium-web-ppt`，做3页“AI门店试点方案”演示，不依赖实拍。先表达试点判断，再画清楚顾客路径，最后用可编辑表格定义指标。没有基线或结果时写待测，不虚构增长或收入。以132的共同版心、198的横向条目和178的单一主对象建立信息秩序。

**文化策展：** 使用 `$premium-web-ppt`，为虚构的“光的秩序”展览制作3页演示。用明黄、墨黑和钴蓝组织强标题、原创几何作品、较密的策展目录。借004的双联关系、131的编辑力度与150的信息分组。中文文字与作品几何均可编辑，所有内容标为策展概念。

## 验证范围

三组最终PPTX均做了结构检查、重新导入及逐页渲染。每套含3页；商务第3页与文化第3页含原生表格。实际检查与编辑性统计见 [verification.md](verification.md)。本仓库的原生渲染检查不等于已在所有 PowerPoint 版本中验收。
