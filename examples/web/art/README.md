# 未完成的日常｜艺术活动官网

原创概念演示。用明黄与黑白双联作品形成张力，一句大中文标题统领首屏，作品说明与展览叙事在下方展开。借鉴004、014、150的图像关系与信息组织，没有复制参考站作品。

## 创作提示词

```text
使用 $premium-web-ppt，为虚构艺术活动“未完成的日常”制作一个网页。
以黄色/黑白双联原创作品为主视觉，只保留一个大中文标题。
展讯、作品说明和策展思路需要可读，手机标题按“未完成的/日常”换行。
制作真实页内导航、手机目录和可展开说明，不添加虚假购票或预约。
用原生SVG创作几何作品，标明本页是原创概念演示。
```
