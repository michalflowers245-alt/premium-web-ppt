# 见山工作室｜编辑式建筑官网

原创概念演示。页面围绕一张建筑竖图建立阅读重心，用暖白、细线、宽窄分栏和固定项目图注组织信息。参考方向是图鉴中的编辑画册、空间材质与建筑档案：006、022、124；没有复用这些品牌的照片、Logo或文案。

## 创作提示词

```text
使用 $premium-web-ppt，为虚构的“见山工作室”制作一个buildless建筑官网。
采用大白边、右侧竖幅建筑图、左侧简短叙述及固定项目元数据。
中文标题有自然语义换行，正文清楚；导航能定位项目与工作方法。
手机重新安排图文比例，保留真实菜单与键盘焦点。
建筑图是GPT生成概念，不写成实景；全部项目标明虚构或概念研究。
```
