# 把官网审美转为 PPT

网页能滚动与交互，PPT需要每页成立且页间有叙述关系。只迁移视觉语法，不把网页截图、导航栏和Cookie弹窗当作PPT模板。

## 转译关系

| 官网元素 | PPT中的作用 | 处理 |
|---|---|---|
| 全屏Hero | 封面/章节/关键结论 | 一张有焦点的图片和简短有意义标题；文字与主体避让 |
| 编辑图文 | 背景/案例/方案解释 | 保留图文比例和对齐轴，长说明另分页面 |
| 产品特写 | 产品、技术、工艺证据 | 配局部细节、标注、参数或应用，不只做大图画册 |
| 作品网格/索引 | 案例组合/路线图/比较 | 有秩序的尺寸差异与编号，避免全稿同款卡片 |
| 章节留白 | 叙述停顿/转折 | 适当留给标题或关键判断，不强行每三页加空白章页 |
| 滚动揭示 | 连续页的信息递进 | 拆成静态逐页可读关系，不用动画掩盖结构不清 |
| Footer图注 | 来源、页码、保密说明 | 控制位置与弱层级，保持必要信息可读 |

## 一套稿的视觉骨架

先遵循用户页数、内容顺序和模板要求；未指定时，按沟通目标决定比例和页数。16:9通常适合屏幕演示，但不能覆盖明确的4:3或竖版要求。

封面、章节、观点、证据、案例、比较、数据、结束页形成几种有意义的母版，同一骨架内保留变化。每页标题尽量表达一个判断；保留真实来源与限定，不把假设写成结果。

以16:9演示为起点，可用左右边距约5%–7%，上下约5%–8%；标题约28–44pt，正文18–26pt，必要图注12–14pt。数字并非强制标准：会议室远观需要更大，书面阅读型材料可更紧凑，内容多时优先拆页或进附录。不能把正文普遍压到小字以适配装饰。

## 中文、图表与可编辑性

- 中文按自然语义换行，避免单字孤行、标点顶行和刻意逐字拉开。中英/数字角色可不同，但别让装饰英文字体替代中文可读性。
- 用真实柱图、折线、流程、表格表达数据关系；简化网格线、直接标注重点、单位与口径。不能为了极简省略基准线或制造错误比例。
- 默认标题、正文、关键数据、图表和表格保持可编辑。摄影、插画、纹理可作为图片。整页栅格化只在用户明确选择或目标格式需要时采用，并说明限制。
- 没有可用大图时选字体驱动、图表驱动或结构驱动页面，不能自动复用参考品牌摄影充当用户案例。
- 图片清晰度需足够，裁切不伤主体；背景图文字可用局部实色底、位置调整或轻遮罩获得对比，避免统一重黑蒙层毁掉图片。

## 成品检查

导出后重新打开并渲染全部页面。先看整套缩略图的节奏、主色、边距和重复度，再看逐页文字、图表、图注与裁切；重点检查最密页、最长标题和深浅背景切换页。确认无溢出、压线、异常替换字体、图片失真和错页。

检查实际PPTX结构或编辑器中的关键文本/图表，确认可编辑性；一张漂亮PNG不证明PPT可编辑。用对应演示制作流程完成文件/包结构检查，但不要把结构通过写成视觉已通过。
